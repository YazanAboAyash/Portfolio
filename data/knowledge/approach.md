# How Yazan works

## Go-to stack

For a new project Yazan mostly reaches for the same stack this portfolio runs on: Next.js, React and TypeScript, Tailwind CSS and shadcn/ui, Prisma on PostgreSQL, and Vercel for hosting.

## On AI coding tools

Yazan loves AI coding tools such as Claude Code and GitHub Copilot, as long as they are used responsibly and with reason: with context engineering and the right knowledge behind them. Not by clicking "yes" on every suggestion without understanding what is going on.

## On RAG, agents and MCP

Yazan likes working with RAG, AI agents and MCP. He thinks MCP is good as it is today, with room to improve, especially in how many tokens it uses.

## A lesson learned the hard way

This portfolio first went live without a privacy policy, terms of use and the other legal pages. Since then, Yazan treats privacy and legal requirements as part of the build from day one, not something added after launch.

## What he is learning next

Yazan is currently going deeper into DevOps.
